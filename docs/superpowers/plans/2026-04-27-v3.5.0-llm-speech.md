# v3.5.0 Phase 3 — LLM-powered in-character speech (L1-L5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the L1-L5 LLM-speech bundle as v3.5.0. The kitten gains an occasional in-character voice that reacts to recent transcript activity (1-in-5 prompts), plus an LLM-generated personality blurb at hatch with the long-standing rename-bug fixed.

**Architecture:** Three independent code paths sharing a tiny `llm.rs` module: (1) per-turn detached `purrgotchi react` worker writes a transient quip-cache file that the statusline reads as a 6-render speech overlay; (2) sync LLM call at `purrgotchi hatch` for the personality blurb, falling back to the existing static table; (3) debug logging on both paths. All LLM paths gate on `ANTHROPIC_API_KEY` presence and degrade silently to static when absent.

**Tech Stack:** Rust 2024, serde, serde_json, plus new dep `ureq` (blocking HTTP, rustls TLS, ~12 transitive deps). Bin-only crate (use `cargo test`, never `--lib`). Repo lives at `rust/` under the project root.

**Spec:** `docs/superpowers/specs/2026-04-27-phase-3-llm-speech-design.md`

```rust
//!
//! Used by `react.rs` (per-turn quips) and `hatch.rs` (one-shot personality
//! blurb). Every error variant is non-fatal at the call site; callers log via
//! `debug::log` and fall back to static behaviour.

use std::env;

const ANTHROPIC_VERSION: &str = "2023-06-01";

    pub system: String,
    pub user: String,
    pub max_tokens: u32,
}

#[derive(Debug)]

    pub text: String,
    pub input_tokens: u32,
    pub output_tokens: u32,
    pub latency_ms: u64,
}

#[derive(Debug)]
pub enum LlmError {
    MissingKey,
    Network(String),
    Http(u16),
    MalformedResponse(String),
    Timeout,
}

/// Reads `ANTHROPIC_API_KEY` from env. Returns `None` for missing or empty.
pub fn api_key() -> Option<String> {
    match env::var("ANTHROPIC_API_KEY") {
        Ok(s) if !s.is_empty() => Some(s),
        _ => None,
    }
}

/// Parse the Anthropic Messages API response JSON into a `HaikuResponse`.
/// Pure; no I/O. The `latency_ms` field is set by the caller after the round-trip.
pub fn parse_haiku_response(body: &str) -> Result<(String, u32, u32), LlmError> {
    let v: serde_json::Value = serde_json::from_str(body)
        .map_err(|e| LlmError::MalformedResponse(format!("json: {e}")))?;
    // Error envelope: {"type":"error","error":{"type":"...","message":"..."}}
    if v.get("type").and_then(|t| t.as_str()) == Some("error") {
        let msg = v.pointer("/error/message").and_then(|m| m.as_str()).unwrap_or("unknown");
        return Err(LlmError::MalformedResponse(format!("api error: {msg}")));
    }
    let text = v.pointer("/content/0/text")
        .and_then(|t| t.as_str())
        .ok_or_else(|| LlmError::MalformedResponse("missing /content/0/text".into()))?
        .to_string();
    let input = v.pointer("/usage/input_tokens")
        .and_then(|t| t.as_u64()).unwrap_or(0) as u32;
    let output = v.pointer("/usage/output_tokens")
        .and_then(|t| t.as_u64()).unwrap_or(0) as u32;
    Ok((text, input, output))
}
```

```rust
pub fn call_haiku(req: HaikuRequest) -> Result<HaikuResponse, LlmError> {
    let key = api_key().ok_or(LlmError::MissingKey)?;
    let body = serde_json::json!({
        "model": HAIKU_MODEL,
        "max_tokens": req.max_tokens,
        "system": req.system,
        "messages": [{"role": "user", "content": req.user}]
    });
    let agent = ureq::AgentBuilder::new()
        .timeout_connect(Duration::from_secs(CONNECT_TIMEOUT_SECS))
        .timeout_read(Duration::from_secs(READ_TIMEOUT_SECS))
        .build();

    let t0 = std::time::Instant::now();
    let resp = agent.post(ANTHROPIC_API_URL)
        .set("x-api-key", &key)
        .set("anthropic-version", ANTHROPIC_VERSION)
        .set("content-type", "application/json")
        .send_json(body);
    let latency_ms = t0.elapsed().as_millis() as u64;

    match resp {
        Ok(r) => {
            let body = r.into_string().map_err(|e| LlmError::Network(e.to_string()))?;
            let (text, input_tokens, output_tokens) = parse_haiku_response(&body)?;
            Ok(HaikuResponse { text, input_tokens, output_tokens, latency_ms })

        Err(ureq::Error::Status(code, _)) => Err(LlmError::Http(code)),
        Err(ureq::Error::Transport(t)) => {
            // ureq surfaces both timeouts and network failures here.
            let s = t.to_string();
            if s.contains("timed out") || s.contains("timeout") {
                Err(LlmError::Timeout)
            } else {
                Err(LlmError::Network(s))
            }
        }
    }
}
```

```rust
//! Persistent cache for the L1 LLM-quip overlay.
//!
//! File: `~/.claude/purrgotchi/llm-quip.json`. Written by the detached
//! `purrgotchi react` worker, consumed by the statusline once per render until
//! `renders_remaining` hits zero. Kept separate from `state.json` so the async
//! worker doesn't race the synchronous `feed`/`pet`/`play`/`treat` writers.

use std::fs;
use std::io::{self, Write};
use std::path::Path;
use std::process;

use serde::{Deserialize, Serialize};

use crate::paths;

const QUIP_RENDERS: u8 = 6;
const QUIP_STALE_SECS: u64 = 5 * 60;

#[derive(Debug, Serialize, Deserialize, Clone, PartialEq, Eq)]
pub struct Quip {
    pub quip: String,
    pub generated_at: u64,
    pub renders_remaining: u8,
}

/// Atomically write a fresh quip with `renders_remaining = QUIP_RENDERS`.
/// Used by the `react` worker only.
pub fn write(text: &str) -> io::Result<()> {
    let q = Quip {
        quip: text.to_string(),
        generated_at: crate::state::now_secs(),
        renders_remaining: QUIP_RENDERS,
    };
    write_quip(&q)
}

fn write_quip(q: &Quip) -> io::Result<()> {
    let dir = paths::state_dir();
    fs::create_dir_all(&dir)?;
    let pid = process::id();
    let tmp = dir.join(format!(".llm-quip.{pid}.tmp"));
    let final_path = paths::quip_cache_file();
    let json = serde_json::to_string_pretty(q)
        .map_err(|e| io::Error::new(io::ErrorKind::InvalidData, e))?;
    {
        let mut f = fs::File::create(&tmp)?;
        f.write_all(json.as_bytes())?;
        f.write_all(b"\n")?;
    }
    match fs::rename(&tmp, &final_path) {
        Ok(()) => Ok(()),
        Err(e) => {
            let _ = fs::remove_file(&tmp);
            Err(e)
        }
    }
}

/// Read the quip file, returning `None` on missing or corrupt.
fn read_inner(path: &Path) -> Option<Quip> {
    let bytes = fs::read(path).ok()?;
    serde_json::from_slice(&bytes).ok()
}

#[cfg(test)]
pub fn read() -> Option<Quip> {
    read_inner(&paths::quip_cache_file())
}

/// Statusline-side: read the active quip, decrement, atomic-write.
/// Returns the quip text when the quip is fresh and has renders left, else None.
/// Deletes the file when it's stale or exhausted.
pub fn consume() -> Option<String> {
    let path = paths::quip_cache_file();
    let mut q = read_inner(&path)?;
    let now = crate::state::now_secs();
    let stale = now.saturating_sub(q.generated_at) > QUIP_STALE_SECS;
    if stale || q.renders_remaining == 0 {
        let _ = fs::remove_file(&path);
        return None;
    }
    let text = q.quip.clone();
    q.renders_remaining -= 1;
    if q.renders_remaining == 0 {
        let _ = fs::remove_file(&path);
    } else {
        let _ = write_quip(&q);
    }
    Some(text)
}
```

```rust
//! L1 worker subcommand: `purrgotchi react <transcript_path>`.
//!
//! Spawned detached from `hooks::turn` after a 1-in-5 dice hit. Reads the tail
//! of the Claude Code transcript JSONL file, builds a Haiku prompt that
//! references the kitten's identity, calls the API, sanitizes the response,
//! and writes the result to `quip_cache`. Errors are non-fatal — every failure
//! path logs and exits 0, leaving the statusline to serve a static line.

use crate::debug;
use crate::llm::{self, HaikuRequest, LlmError};
use crate::quip_cache;
use crate::state::{self, State};

const TRANSCRIPT_BUDGET_BYTES: usize = 8 * 1024;
const QUIP_HARD_CAP_CHARS: usize = 80;
const REACT_MAX_TOKENS: u32 = 50;
const TOOL_INPUT_PREVIEW_CHARS: usize = 200;
const TOOL_OUTPUT_PREVIEW_CHARS: usize = 200;
const USER_MSG_MAX_CHARS: usize = 500;
const ASSISTANT_MSG_MAX_CHARS: usize = 800;
const RECENT_TOOL_CALLS: usize = 5;

#[derive(Debug, Default, PartialEq, Eq)]
pub struct TranscriptTail {
    pub last_user: String,
    pub last_assistant: String,
    pub recent_tool_calls: Vec<ToolCall>,
}

#[derive(Debug, Default, PartialEq, Eq)]
pub struct ToolCall {
    pub name: String,
    pub input_preview: String,
    pub output_preview: String,
}

impl TranscriptTail {
    pub fn is_empty(&self) -> bool {
        self.last_user.is_empty()
            && self.last_assistant.is_empty()
            && self.recent_tool_calls.is_empty()
    }
}

/// Truncate a string to `max_chars` characters (not bytes), respecting char
/// boundaries.
fn truncate_chars(s: &str, max_chars: usize) -> String {
    s.chars().take(max_chars).collect()
}

/// Read the Claude Code transcript JSONL file and extract a structured tail.
/// Returns `None` if the file is missing or unreadable. Returns `Some(empty)`
/// if the file exists but yields nothing usable — caller should treat empty
/// as "no quip to generate" and skip the API call.
pub fn read_transcript_tail(path: &str) -> Option<TranscriptTail> {
    let bytes = std::fs::read(path).ok()?;
    let text = String::from_utf8_lossy(&bytes);
    Some(parse_transcript_jsonl(&text))
}

/// Pure parser. Walks JSONL backward, extracting the last user message, last
/// assistant message (text only — no tool_use blocks), and last N tool-call
/// pairs (tool_use + tool_result on the closest match by tool_use_id).
pub fn parse_transcript_jsonl(text: &str) -> TranscriptTail {
    use std::collections::HashMap;
    let mut last_user = String::new();
    let mut last_assistant = String::new();
    let mut tool_uses: Vec<(String, String, String)> = Vec::new(); // (id, name, input_preview)
    let mut tool_results: HashMap<String, String> = HashMap::new();

    for line in text.lines() {
        let line = line.trim();
        if line.is_empty() {
            continue;
        }
        let v: serde_json::Value = match serde_json::from_str(line) {
            Ok(v) => v,
            Err(_) => continue,
        };
        // Claude Code transcript entries look like:
        //   {"type":"user","message":{"role":"user","content":"..."}}
        // or content is an array of blocks (with tool_use / tool_result blocks).
        let entry_type = v.get("type").and_then(|t| t.as_str()).unwrap_or("");
        let msg = v.get("message").unwrap_or(&serde_json::Value::Null);
        let role = msg.get("role").and_then(|r| r.as_str()).unwrap_or(entry_type);

        match role {
            "user" => {
                if let Some(text) = extract_user_text(msg) {
                    if !text.is_empty() {
                        last_user = truncate_chars(&text, USER_MSG_MAX_CHARS);
                    }
                }
                // tool_result blocks arrive on user messages.
                if let Some(content) = msg.get("content").and_then(|c| c.as_array()) {
                    for block in content {
                        let bt = block.get("type").and_then(|t| t.as_str()).unwrap_or("");
                        if bt == "tool_result" {
                            let id = block.get("tool_use_id").and_then(|t| t.as_str()).unwrap_or("").to_string();
                            let txt = extract_block_text(block);
                            if !id.is_empty() {
                                tool_results.insert(
                                    id,
                                    truncate_chars(&txt, TOOL_OUTPUT_PREVIEW_CHARS),
                                );
                            }
                        }
                    }
                }
            }
            "assistant" => {
                let mut text_parts: Vec<String> = Vec::new();
                if let Some(content) = msg.get("content").and_then(|c| c.as_array()) {
                    for block in content {
                        let bt = block.get("type").and_then(|t| t.as_str()).unwrap_or("");
                        if bt == "text" {
                            if let Some(t) = block.get("text").and_then(|t| t.as_str()) {
                                text_parts.push(t.to_string());
                            }
                        } else if bt == "tool_use" {
                            let id = block.get("id").and_then(|t| t.as_str()).unwrap_or("").to_string();
                            let name = block.get("name").and_then(|t| t.as_str()).unwrap_or("").to_string();
                            let input_str = block.get("input")
                                .map(|i| i.to_string())
                                .unwrap_or_default();
                            tool_uses.push((id, name, truncate_chars(&input_str, TOOL_INPUT_PREVIEW_CHARS)));
                        }
                    }
                } else if let Some(s) = msg.get("content").and_then(|c| c.as_str()) {
                    text_parts.push(s.to_string());
                }
                let joined = text_parts.join(" ");
                if !joined.is_empty() {
                    last_assistant = truncate_chars(&joined, ASSISTANT_MSG_MAX_CHARS);
                }
            }
            _ => {}
        }
    }

    let mut recent: Vec<ToolCall> = tool_uses.iter().rev().take(RECENT_TOOL_CALLS).map(|(id, name, input)| {
        let output = tool_results.get(id).cloned().unwrap_or_default();
        ToolCall { name: name.clone(), input_preview: input.clone(), output_preview: output }
    }).collect();
    recent.reverse();

    TranscriptTail { last_user, last_assistant, recent_tool_calls: recent }
}

fn extract_user_text(msg: &serde_json::Value) -> Option<String> {
    if let Some(s) = msg.get("content").and_then(|c| c.as_str()) {
        return Some(s.to_string());
    }
    if let Some(arr) = msg.get("content").and_then(|c| c.as_array()) {
        let mut out = String::new();
        for block in arr {
            let bt = block.get("type").and_then(|t| t.as_str()).unwrap_or("");
            if bt == "text" {
                if let Some(t) = block.get("text").and_then(|t| t.as_str()) {
                    if !out.is_empty() { out.push(' '); }
                    out.push_str(t);
                }
            }
        }
        if !out.is_empty() {
            return Some(out);
        }
    }
    None
}

fn extract_block_text(block: &serde_json::Value) -> String {
    if let Some(s) = block.get("content").and_then(|c| c.as_str()) {
        return s.to_string();
    }
    if let Some(arr) = block.get("content").and_then(|c| c.as_array()) {
        let mut out = String::new();
        for inner in arr {
            if let Some(t) = inner.get("text").and_then(|t| t.as_str()) {
                if !out.is_empty() { out.push(' '); }
                out.push_str(t);
            }
        }
        return out;
    }
    String::new()
}

/// Build the Haiku request from kitten state + transcript tail.
/// Mood is a best-effort guess — the worker doesn't have the live payload, so
/// only fed/pet/play/treat-derived moods are available; panic/alert never fire here.
pub fn build_prompt(s: &State, mood: &str, tail: &TranscriptTail) -> HaikuRequest {
    let peak_idx = s.stats.iter().enumerate()
        .max_by_key(|(_, &v)| v).map(|(i, _)| i).unwrap_or(0);
    let dump_idx = s.stats.iter().enumerate()
        .min_by_key(|(_, &v)| v).map(|(i, _)| i).unwrap_or(4);
    let names = crate::identity::STAT_NAMES;
    let peak = names[peak_idx];
    let dump = names[dump_idx];
    let rendered_personality = s.personality.replace("{name}", &s.name);

    let system = format!(
        "You are the inner voice of {name}, a {rarity} {breed} cat with peak {peak} and \
dump {dump}. Personality: {personality}.\n\n\
You watch the human work in their terminal. Sometimes you make a short, dry, \
in-character remark about what they just did. Speak as the cat — first person \
or third person, your choice — but keep it to ONE short line, ≤60 characters.\n\n\
Voice rules:\n\
- React to the user's last action or message; don't summarize.\n\
- Cat-flavored vocabulary is welcome (mrow, purr, paw) but don't lean on it.\n\
- No emoji. No quotation marks around the line. No preamble. No trailing period \
unless the line genuinely ends in one.\n\
- If nothing in the transcript is interesting, output exactly: mrow.",
        name = s.name,
        rarity = s.rarity,
        breed = s.breed,
        peak = peak,
        dump = dump,
        personality = rendered_personality,
    );

    let mut user = String::new();
    user.push_str("Here's what just happened:\n\n");
    if !tail.last_user.is_empty() {
        user.push_str(&format!("USER: {}\n\n", tail.last_user));
    }
    if !tail.last_assistant.is_empty() {
        user.push_str(&format!("A: {}\n\n", tail.last_assistant));
    }
    if !tail.recent_tool_calls.is_empty() {
        user.push_str("RECENT TOOL CALLS:\n");
        for tc in &tail.recent_tool_calls {
            user.push_str(&format!("- {}({}) → {}\n", tc.name, tc.input_preview, tc.output_preview));
        }
        user.push('\n');
    }
    user.push_str(&format!("Mood signal: {mood}"));

    // Defensive cap: even if every component obeys its own limit, the joined
    // string could in theory exceed the budget. Truncate at a char boundary.
    if user.len() > TRANSCRIPT_BUDGET_BYTES {
        user = truncate_chars(&user, TRANSCRIPT_BUDGET_BYTES);
    }

    HaikuRequest { system, user, max_tokens: REACT_MAX_TOKENS }
}

/// Trim an LLM response down to a single safe line for the speech bubble.
pub fn sanitize_quip(raw: &str) -> String {
    // 1. Take first non-empty line.
    let line = raw.lines().map(str::trim).find(|s| !s.is_empty()).unwrap_or("");
    // 2. Replace any remaining newlines (defensive — first-line shouldn't have any).
    let line = line.replace(['\n', '\r'], " ");
    // 3. Strip surrounding matched quotes.
    let line = strip_quotes(&line);
    // 4. Hard char cap with word-boundary truncation.
    truncate_at_word_boundary(&line, QUIP_HARD_CAP_CHARS)
}

fn strip_quotes(s: &str) -> String {
    let trimmed = s.trim();
    let bytes = trimmed.as_bytes();
    if bytes.len() >= 2 {
        let first = bytes[0];
        let last = bytes[bytes.len() - 1];
        if (first == b'"' && last == b'"') || (first == b'\'' && last == b'\'') {
            return trimmed[1..trimmed.len() - 1].to_string();
        }
    }
    trimmed.to_string()
}

fn truncate_at_word_boundary(s: &str, max_chars: usize) -> String {
    if s.chars().count() <= max_chars {
        return s.to_string();
    }
    let head: String = s.chars().take(max_chars).collect();
    if let Some(idx) = head.rfind(' ') {
        head[..idx].to_string()
    } else {
        head
    }
}

/// Top-level entry point for `purrgotchi react <transcript_path>`.
/// Always exits 0 — every failure is silent + logged.
pub fn run(transcript_path: &str) {
    let _ = run_inner(transcript_path);
}

fn run_inner(transcript_path: &str) -> Option<()> {
    if llm::api_key().is_none() {
        debug::log("[llm] react skip reason=missing_key");
        return None;
    }
    let s = state::load()?;
    if s.breed.is_empty() {
        debug::log("[llm] react skip reason=unhatched");
        return None;
    }
    let tail = read_transcript_tail(transcript_path).unwrap_or_default();
    if tail.is_empty() {
        debug::log("[llm] react skip reason=empty_transcript");
        return None;
    }
    let mood = best_effort_mood(&s);
    let req = build_prompt(&s, mood, &tail);
    match llm::call_haiku(req) {
        Ok(resp) => {
            debug::log(&format!(
                "[llm] react ok latency_ms={} in_tok={} out_tok={}",
                resp.latency_ms, resp.input_tokens, resp.output_tokens,
            ));
            let q = sanitize_quip(&resp.text);
            if q.is_empty() {
                debug::log("[llm] react skip reason=empty_quip_after_sanitize");
                return None;
            }
            let _ = quip_cache::write(&q);
        }
        Err(e) => {
            debug::log(&format!("[llm] react fail err={e:?}"));
        }
    }
    Some(())
}

/// Pick a mood string from state alone. Cannot derive panic/alert (those need
/// context %, which the worker doesn't have). Defaults to calm.
fn best_effort_mood(s: &State) -> &'static str {
    let now = state::now_secs();
    let fed_delta = (now as i64) - (s.last_fed_at as i64);
    if fed_delta > 8 * 3600 { return "hungry"; }
    let last = [s.last_pet_at, s.last_played_at, s.last_treated_at].iter().copied().max().unwrap_or(0);
    if last != 0 && now.saturating_sub(last) < 180 {
        return "happy";
    }
    "calm"
}
```

```rust
//! Cross-platform detached subprocess spawn for fire-and-forget workers.
//!
//! Used by `hooks::turn` to launch `purrgotchi react` without blocking the
//! UserPromptSubmit hook. Failures (couldn't resolve current_exe, spawn failed)
//! are silent — the caller falls through to its existing behaviour.

use std::process::{Command, Stdio};

/// Spawn `purrgotchi <args...>` detached from the current process.
/// Drops the resulting `Child` handle so the parent can exit immediately
/// without waiting. All stdio is nulled so the child cannot keep the parent's
/// pipes open.
pub fn detached_self(args: &[&str]) {
    let exe = match std::env::current_exe() {
        Ok(p) => p,
        Err(_) => return,
    };
    let mut cmd = Command::new(exe);
    cmd.args(args)
        .stdin(Stdio::null())
        .stdout(Stdio::null())
        .stderr(Stdio::null());

    #[cfg(windows)]
    {
        use std::os::windows::process::CommandExt;
        const DETACHED_PROCESS: u32 = 0x0000_0008;
        const CREATE_NO_WINDOW: u32 = 0x0800_0000;
        cmd.creation_flags(DETACHED_PROCESS | CREATE_NO_WINDOW);
    }

    // Intentionally drop the Child handle — parent exits without waiting.
    let _ = cmd.spawn();
}
```

```rust
const HATCH_BLURB_HARD_CAP_CHARS: usize = 200;

/// Try to generate an LLM personality blurb at hatch. Returns `None` on any
/// failure or when the API key is missing. Caller falls back to whatever
/// `generate_from_seed` already stored.
fn maybe_llm_blurb(s: &state::State) -> Option<String> {
    if crate::llm::api_key().is_none() {
        return None;
    }
    if std::env::var("PURR_FORCE_STATIC_BLURB").is_ok() {
        return None;
    }
    let peak_idx = s.stats.iter().enumerate()
        .max_by_key(|(_, &v)| v).map(|(i, _)| i)?;
    let dump_idx = s.stats.iter().enumerate()
        .min_by_key(|(_, &v)| v).map(|(i, _)| i)?;
    let peak = identity::STAT_NAMES[peak_idx];
    let dump = identity::STAT_NAMES[dump_idx];

- No emoji. No quotation marks. No preamble.".to_string();
    let user = format!(

        s.rarity, s.breed,
    );
    let req = crate::llm::HaikuRequest { system, user, max_tokens: HATCH_MAX_TOKENS };

    eprintln!("✨ summoning personality…");
    match crate::llm::call_haiku(req) {

            }
        }

            None
        }

fn clean_hatch_blurb(raw: &str) -> String {
    let trimmed = raw.trim();
    let stripped = if (trimmed.starts_with('"') && trimmed.ends_with('"'))
        || (trimmed.starts_with('\'') && trimmed.ends_with('\''))
    {
        &trimmed[1..trimmed.len() - 1]
    } else {
        trimmed
    };
    let single = stripped.replace(['\n', '\r'], " ");
    single.chars().take(HATCH_BLURB_HARD_CAP_CHARS).collect()
}

/// Validate: the blurb either uses `{name}` literal OR contains no proper
/// nouns (no capitalized non-sentence-start words). The cheap proper-noun
/// check is "every word that's both capitalized and not the first word of a
/// sentence is a proper noun".
fn validate_blurb(b: &str) -> bool {
    if b.is_empty() {
        return false;
    }
    if b.contains("{name}") {
        return true;
    }
    // No placeholder — only allow if there are no proper nouns.
    let mut sentence_start = true;
    for word in b.split_whitespace() {
        let w = word.trim_matches(|c: char| !c.is_alphanumeric());
        if w.is_empty() {
            // pure punctuation token — keep current sentence_start
            continue;
        }
        let is_cap = w.chars().next().is_some_and(|c| c.is_uppercase());
        if is_cap && !sentence_start {
            return false; // proper noun without placeholder → reject
        }
        // After a sentence-ending word, the next word starts a sentence.
        sentence_start = word.ends_with('.') || word.ends_with('!') || word.ends_with('?');
    }
    true
}
```

```markdown
## v3.5.0 — 2026-04-XX (replace XX with the actual release day)

**Phase 3 — LLM-powered in-character speech (L1-L5).**

- L1: Per-turn LLM reaction overlay. On UserPromptSubmit, the kitten rolls a
  1-in-5 die; on hit, a detached `purrgotchi react` worker reads the recent
  transcript tail (last user prompt + last assistant message + last 5 tool
  calls), calls Claude Haiku 4.5 with the kitten's identity and personality
  baked into the system prompt, and writes a one-line quip to a cache file.
- L2: Statusline displays the quip in a pink speech bubble for 6 renders,
  then reverts to static mood speech. Falls back silently to static when the
  cache is missing, stale (>5 min), or no API key is set.
- L3: All LLM paths gate on `ANTHROPIC_API_KEY`. Absent → static behaviour;
  no errors, no prompts.
- L4: Debug log records latency, input/output token counts, and model for
  every LLM call (visible with `PURR_DEBUG=1`).
- L5: At hatch, generate the personality blurb via Haiku when the API key is
  present (with `✨ summoning personality…` indicator). All blurbs (LLM and
  static) are now stored with literal `{name}` placeholder and substituted at
  render — fixes the long-standing rename bug where renaming a kitten left
  the old name baked into the card.
- Speech bubble priority: Celebration > Birthday > LLM-quip > Mood.
- New deps: `ureq` (blocking HTTP, rustls TLS, ~12 transitive deps).
- New cache file: `~/.claude/purrgotchi/llm-quip.json` (overlay state, kept
  separate from `state.json` to avoid races with the synchronous hooks).
- Cost: ~$0.014–$0.056/day at typical usage (10–40 react calls + occasional
  hatch). Tracked separately from `lifetime_cost_usd` (out of scope here).
```

## Cost reference (locked from spec)

- 50–200 prompts/day × 20% hit rate × $0.0014 ≈ $0.014–$0.056/day.
- Hatch is one-shot, ~$0.0005, negligible.
- Costs are user-side Anthropic API spend (separate bucket from Claude Code's `lifetime_cost_usd`).
