# v4.0.0 Phase 0 — Rust JSON Surface Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the `purrgotchi` binary a versioned, machine-readable `--json` surface (feed/turn/pet/play/treat/rename/stats/card + new `frame`, `cost`, `quip-prompt`, `quip-store`) and an `install.sh --uninstall-hooks`, without changing a single byte of the classic statusline output.

**Architecture:** Two test seams land first (`PURR_STATE_DIR`, `PURR_NOW`), then byte-exact golden tests of the statusline are recorded from the real binary. Only then is `colors.rs`/`render.rs`/`statusline.rs` refactored onto `Vec<Span>` with an ANSI printer (byte-identical) and a JSON printer. Legacy renderers that stay ANSI-string based (card, pet/play/treat prose) get their JSON through a small SGR parser instead of a rewrite. `statusline::run` is split into a pure `kitten_view` (read) and `advance` (timers) so `frame` can be read-only.

**Tech Stack:** Rust 2024, bin-only crate at `rust/` (no `lib.rs`), serde/serde_json (already deps), bash + jq for `install.sh`. Integration tests in `rust/tests/` drive the real binary through `env!("CARGO_BIN_EXE_purrgotchi")`.

**Spec:** `docs/superpowers/specs/2026-10-17-v4.0.0-claude-code-mod-design.md` — Phase 0 = §3.1, §4.1 (`--uninstall-hooks`, `feed --count`), §5 row 0, §6, §7.4/§7.8, §8 (`PURR_STATE_DIR`). ## Global Constraints

- Bin-only crate: **no `lib.rs` — do not create one.** Unit tests live in `#[cfg(test)] mod tests` inside each module; black-box tests live in `rust/tests/*.rs` and spawn the binary. Run tests with plain `cargo test` from `rust/`.
- **Zero new dependencies** — not even dev-dependencies (no `tempfile`, no `insta`). `serde`/`serde_json` are already deps and are usable from `rust/tests/`.
- **Never `std::env::set_var` in tests** (parallel threads race; it is also `unsafe` in edition 2024). Env-reading functions get a pure `*_from(...)` twin; unit tests target the twin. Env-dependent behaviour is tested by spawning the binary with `Command::env`.
- **Never run the binary against the real `~/.claude/purrgotchi`.** Manual runs always use `HOME=$(mktemp -d) PURR_STATE_DIR=$(mktemp -d) ./target/debug/purrgotchi …`. Integration tests use `tests/common::Sandbox`, which clears the child env and sets both.
- **The classic statusline output must stay byte-identical.** The goldens from Task 2 are the contract. If a golden changes, the change is a bug — never re-record goldens after Task 2 (`UPDATE_GOLDEN=1` is for Task 2 only).
- All state mutations go through `state::locked_update` on a FRESH copy with guards re-checked inside the closure. No `State` struct changes in Phase 0 (no new persisted fields).
- No `_ =>` wildcard arms when matching `CelebrationKind`, `PlaygroundScene`, `SceneTransition`, `PetResult`, `PlayResult`, `TreatResult`. (String / `u8` colour-id matches may use `_`.)
- JSON contract rules (apply to every `--json` output):
  - Exactly **one line** of JSON on stdout (`serde_json::to_string`, not pretty) — NDJSON-friendly for the later `serve` mode.
  - Every object has `"v": 1` and `"ok": bool`.
  - Errors: stdout gets `{"v":1,"ok":false,"error":"<code>","message":"<text>"}`; stderr keeps the exact human error text the classic path prints; the exit code is the same as the classic path.
  - Adding fields keeps `v: 1`. Renaming/removing/retyping a field bumps `v`. Consumers must ignore unknown keys.
  - `CelebrationKind::None` / `PlaygroundScene::None` are emitted as JSON `null`, never the string `"None"`.
- `PURR_NOW` and `PURR_STATE_DIR` are dev/test backdoors like `PURR_FORCE_SCENE`: no-ops when unset; keep them out of the README.
- Builds stay at zero warnings: `cargo build 2>&1 | grep -c '^warning'` → `0`. If `cargo clippy` is installed (`rustup component add clippy`), `cargo clippy --all-targets -- -D warnings` must be clean too.
- Commits: conventional (`feat:`, `test:`, `refactor:`), message describes what changed. **No `Co-Authored-By` lines.** Never `git add` anything under `docs/superpowers/specs/`. No version bump (stays `3.8.0`; 4.0.0 is not Phase 0).

**Deviations from spec (intentional — do not "fix" them back):**
- §3.1 says pet/play/treat return `"message": "<the same prose>"`. The prose embeds ANSI escapes (`hooks.rs:187-196`, `234-243`, `289-305`). JSON `message` is the ANSI-stripped prose; the classic stdout is untouched.
- §3.1 calls `stats` "ANSI/box text". `format_stats_card` (`hooks.rs:354-410`) is plain text with zero ANSI; only `card` is coloured. `stats --json` lines are single unstyled spans; `--plain` is accepted and identical to the default.
- §3.1 implies all renderers move to `Vec<Span>`. Only the statusline (and the playground canvas, for JSON) does. `card` and the action messages keep their string renderers; their JSON goes through `span::parse_ansi`. One source of truth either way; far less byte-identity risk.
- §4.3/§7.4/§7.8 describe a double-tick bug when two renderers advance celebrations. The code already prevents it: the countdown is gated on the shared `last_celebration_tick_at` re-checked under the lock (`statusline.rs:445-464`), so N renderers decrement at most once per `CELEBRATION_TICK_SECS = 2`. The real gap is the inverse: a read-only `frame` with no statusline installed would never clear celebrations or start scenes. Hence `frame` is read-only by default and `frame --advance` runs the same `advance` step (safe alongside the statusline because of that gate).
- §4.6 says the quip prompt comes "from `speech.rs`". It is `react::build_prompt` (`react.rs:206`), which needs a transcript tail. `quip-prompt` takes optional `{last_user,last_assistant}` JSON on stdin.
- §3.1 `frame` field list is extended (mood, stage, level, coins, bond, `speech_source`, `celebration.remaining_ticks`); `pixels` is **not** added (Phase 3b, additive).
- `frame --tick T` = animation tick: sprite frame parity is `T % 2`; everything else uses the wall clock (`state::now_secs()`). Default `T = now`.

```rust
//! Shared harness for integration tests. Every test runs the real binary in a
//! sandbox: HOME and PURR_STATE_DIR both point into a fresh temp dir and the
//! child's environment is cleared, so the developer's own PURR_* / TZ /
//! COLUMNS / API keys can never leak into results. No extra dependencies.
#![allow(dead_code)]

use std::collections::BTreeMap;
use std::io::Write;
use std::path::{Path, PathBuf};
use std::process::{Command, Output, Stdio};
use std::sync::atomic::{AtomicU32, Ordering};

static COUNTER: AtomicU32 = AtomicU32::new(0);

pub struct Sandbox {
    pub root: PathBuf,
    pub home: PathBuf,
    pub state: PathBuf,
}

impl Sandbox {
    pub fn new(tag: &str) -> Self {
        let n = COUNTER.fetch_add(1, Ordering::SeqCst);
        let root = std::env::temp_dir().join(format!("purr-it-{tag}-{}-{n}", std::process::id()));
        // read_git_branch walks up from the payload cwd. A sandbox inside the
        // repo would find the repo's own .git and leak the real branch name.
        let repo = Path::new(env!("CARGO_MANIFEST_DIR")).parent().unwrap().to_path_buf();
        assert!(!root.starts_with(&repo), "sandbox {root:?} is inside the repo");
        let _ = std::fs::remove_dir_all(&root);
        let home = root.join("home");
        let state = root.join("state");
        std::fs::create_dir_all(&home).unwrap();
        std::fs::create_dir_all(&state).unwrap();
        Sandbox { root, home, state }
    }

    pub fn cmd(&self, args: &[&str]) -> Command {
        let mut c = Command::new(env!("CARGO_BIN_EXE_purrgotchi"));
        c.args(args)
            .env_clear()
            .env("PATH", std::env::var_os("PATH").unwrap_or_default())
            .env("HOME", &self.home)
            .env("USERPROFILE", &self.home)
            .env("PURR_STATE_DIR", &self.state);
        c
    }

    /// Spawn with `stdin` piped in plus extra env vars; returns the Output.
    pub fn run(&self, args: &[&str], stdin: &str, env: &[(&str, &str)]) -> Output {
        let mut c = self.cmd(args);
        for (k, v) in env {
            c.env(k, v);
        }
        c.stdin(Stdio::piped()).stdout(Stdio::piped()).stderr(Stdio::piped());
        let mut child = c.spawn().expect("spawn purrgotchi");
        // Commands that never read stdin (feed) may exit first → EPIPE. Ignore.
        let _ = child.stdin.take().unwrap().write_all(stdin.as_bytes());
        child.wait_with_output().expect("wait purrgotchi")
    }

    pub fn write_state(&self, v: &serde_json::Value) {
        std::fs::write(self.state.join("state.json"), serde_json::to_string_pretty(v).unwrap()).unwrap();
    }

    pub fn read_state(&self) -> serde_json::Value {
        serde_json::from_slice(&std::fs::read(self.state.join("state.json")).unwrap()).unwrap()
    }

    /// Every regular file directly under the state dir → bytes (the state dir
    /// is flat). Used for "this command wrote nothing" assertions.
    pub fn snapshot(&self) -> BTreeMap<String, Vec<u8>> {
        let mut m = BTreeMap::new();
        for e in std::fs::read_dir(&self.state).unwrap().flatten() {
            if e.path().is_file() {
                m.insert(e.file_name().to_string_lossy().into_owned(), std::fs::read(e.path()).unwrap());
            }
        }
        m
    }
}

impl Drop for Sandbox {
    fn drop(&mut self) {
        let _ = std::fs::remove_dir_all(&self.root);
    }
}
```

/// Dev/test clock override (keep out of README): PURR_NOW=<unix seconds>.
/// Unset → the real clock; behaviour is unchanged.
pub fn now_override() -> Option<u64> {
    now_override_from(std::env::var("PURR_NOW").ok().as_deref())
}

pub(crate) fn now_override_from(v: Option<&str>) -> Option<u64> {
    v?.trim().parse::<u64>().ok()

pub fn now_secs() -> u64 {
    if let Some(n) = now_override() {
        return n;
    }
    SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(|d| d.as_secs())
        .unwrap_or(0)
}

/// Recursive object merge: keys in `patch` overwrite / descend into `base`.
pub fn merge(base: &mut Value, patch: Value) {
    match (base, patch) {
        (Value::Object(b), Value::Object(p)) => {
            for (k, v) in p {
                merge(b.entry(k).or_insert(Value::Null), v);
            }
        }
        (b, p) => *b = p,
    }
}

/// Drop every `ESC [ … <letter>` sequence.
pub fn strip_ansi(s: &str) -> String {
    let mut out = String::new();
    let mut it = s.chars().peekable();
    while let Some(c) = it.next() {
        if c == '\x1b' && it.peek() == Some(&'[') {
            it.next();
            for d in it.by_ref() {
                if d.is_ascii_alphabetic() {
                    break;
                }
            }
        } else {
            out.push(c);
        }
    }
    out
}

**Model:** opus

**Byte-identity rules the printer must honour (each one is load-bearing for a golden):**
1. **Attribute order is not canonical today**: shiny rarity = `BOLD|DIM` then colour (`colors.rs:39-40`); `LV:` value = colour then `BOLD` (`statusline.rs:388`); `NETRUNNER` = `BOLD` then colour (`:267`); hungry speech = `DIM` then `CYAN` (`:225`). So `Span.attrs` is an **ordered `Vec<Attr>`** and the ANSI printer emits them in order.
2. A styled span prints `attrs + text + RESET` **even when `text` is empty** — `{C_PINK}{pre_rail}{C_RESET}` with a zero-length rail is in the goldens.
3. An unstyled span prints its text raw (no RESET).
4. The printer never merges adjacent spans — `h7` is two PINK spans (`{C_PINK}╚{C_RESET}{C_PINK}{rail}╝{C_RESET}`).
5. **Do not touch `Canvas::emit` (`playground.rs:225-250`)** — it emits `RESET+colour` on every colour change (including back to background) plus a trailing RESET per row; the generic span printer cannot reproduce that. Scene rows stay ANSI strings in the statusline path; Task 7 adds a separate `emit_spans` for JSON.
6. Plain width of a span row = Σ `text.chars().count()` — identical to today's `plain` strings, which always equal the ANSI string minus escapes.

use serde::{Deserialize, Serialize};

use crate::colors::{Attr, Rgb, C_RESET};

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Span {
    pub text: String,
    /// Ordered. The ANSI printer emits them in this order — byte-identity with
    /// the pre-v4 format strings depends on it (shiny = BOLD then colour,
    /// `LV:` = colour then BOLD).
    pub attrs: Vec<Attr>,
}

impl Span {
    pub fn new(text: impl Into<String>, attrs: &[Attr]) -> Self {
        Span { text: text.into(), attrs: attrs.to_vec() }
    }
    pub fn width(&self) -> usize {
        self.text.chars().count()
    }
}

pub fn plain(t: impl Into<String>) -> Span {
    Span::new(t, &[])
}
pub fn dim(t: impl Into<String>) -> Span {
    Span::new(t, &[Attr::Dim])
}
pub fn bold(t: impl Into<String>) -> Span {
    Span::new(t, &[Attr::Bold])
}
pub fn fg(t: impl Into<String>, c: Rgb) -> Span {
    Span::new(t, &[Attr::Fg(c)])
}

/// Display width (chars) — the repo-wide plain-width convention.
pub fn width(spans: &[Span]) -> usize {
    spans.iter().map(Span::width).sum()
}

pub fn to_plain(spans: &[Span]) -> String {
    spans.iter().map(|s| s.text.as_str()).collect()
}

pub fn attrs_ansi(attrs: &[Attr]) -> String {
    attrs.iter().map(|a| a.ansi()).collect()
}

/// ANSI printer. Unstyled → raw text. Styled → attrs (in order) + text +
/// RESET, even for empty text. Never merges spans.
pub fn to_ansi(spans: &[Span]) -> String {
    let mut out = String::new();
    for s in spans {
        if s.attrs.is_empty() {
            out.push_str(&s.text);
            continue;
        }
        out.push_str(&attrs_ansi(&s.attrs));
        out.push_str(&s.text);
        out.push_str(C_RESET);
    }
    out
}

/// JSON wire form (spec §3.1): `{ "text", "fg"?: "#rrggbb", "bold"?: true, "dim"?: true }`.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct JsonSpan {
    pub text: String,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub fg: Option<String>,
    #[serde(default, skip_serializing_if = "std::ops::Not::not")]
    pub bold: bool,
    #[serde(default, skip_serializing_if = "std::ops::Not::not")]
    pub dim: bool,
}

impl From<&Span> for JsonSpan {
    fn from(s: &Span) -> Self {
        JsonSpan {
            text: s.text.clone(),
            fg: s.attrs.iter().rev().find_map(|a| match a {
                Attr::Fg(c) => Some(c.hex()),
                Attr::Bold | Attr::Dim => None,
            }),
            bold: s.attrs.contains(&Attr::Bold),
            dim: s.attrs.contains(&Attr::Dim),
        }
    }
}

/// JSON printer.
pub fn to_json(spans: &[Span]) -> Vec<JsonSpan> {
    spans.iter().map(JsonSpan::from).collect()
}

/// Span twin of `pad_col`: append plain spaces up to `w` columns. Never trims —
/// callers shorten oversized values first (see `truncate_tail`).
pub fn pad_spans(mut spans: Vec<Span>, w: usize) -> Vec<Span> {
    let pad = w.saturating_sub(width(&spans));
    spans.push(plain(" ".repeat(pad)));
    spans
}

/// Span twin of `anchor_col`: left block, pink `│` at the column midpoint, right block.
pub fn anchor_spans(mut left: Vec<Span>, right: Vec<Span>, w: usize) -> Vec<Span> {
    let half_l = w.saturating_sub(3) / 2;
    let half_r = w.saturating_sub(3) - half_l;
    let l_pad = half_l.saturating_sub(width(&left));
    let r_pad = half_r.saturating_sub(width(&right));
    left.push(plain(format!("{} ", " ".repeat(l_pad))));
    left.push(fg("│", PINK));
    left.push(plain(" "));
    left.extend(right);
    left.push(plain(" ".repeat(r_pad)));
    left
}

/// Span twin of `close_row`: `║` + inner + padding + `║`, bars in pink.
pub fn close_row_spans(inner: Vec<Span>, box_width: usize) -> Vec<Span> {
    let pad = box_width.saturating_sub(width(&inner));
    let mut row = vec![fg("║", PINK)];
    row.extend(inner);
    row.push(plain(" ".repeat(pad)));
    row.push(fg("║", PINK));
    row
}

pub fn flag_value<'a>(args: &'a [String], flag: &str) -> Option<&'a str> {
    let i = args.iter().skip(2).position(|a| a == flag)? + 2;
    args.get(i + 1).map(String::as_str)
}

/// Positional args after the subcommand. Only the listed flags count as flags
/// (value flags also swallow the next arg); any other dash-word stays
/// positional, so `rename -Kitty` keeps working as it always has.
pub fn positionals<'a>(args: &'a [String], bool_flags: &[&str], value_flags: &[&str]) -> Vec<&'a str> {
    let mut out = Vec::new();
    let mut i = 2;
    while i < args.len() {
        let a = args[i].as_str();
        if bool_flags.contains(&a) {
            i += 1;
        } else if value_flags.contains(&a) {
            i += 2;
        } else {
            out.push(a);
            i += 1;
        }
    }
    out
}

/// Priority for picking one celebration out of a `--count` batch. Mirrors the
/// detection order inside `apply_feed_dispatch`.
pub(crate) fn celebration_rank(k: CelebrationKind) -> u8 {
    match k {
        CelebrationKind::MilestoneCenturion
        | CelebrationKind::MilestoneVeteran
        | CelebrationKind::MilestoneMaster
        | CelebrationKind::MilestoneLegendary => 4,
        CelebrationKind::EvolvingYoung | CelebrationKind::EvolvingAdult => 3,
        CelebrationKind::LevelUp => 2,
        CelebrationKind::Streak => 1,
        CelebrationKind::RandomDrop | CelebrationKind::Greeting | CelebrationKind::None => 0,
    }
}

/// Credit `count` tool calls in one locked write. `count == 1` is exactly the
/// classic `feed`. For larger batches the state ends up holding the
/// highest-ranked celebration of the batch (ties → the later one), so a streak
/// can't overwrite a milestone that happened earlier in the same batch.
pub(crate) fn apply_feed_batch(s: &mut crate::state::State, count: u32, now: u64) -> FeedBatch {
    let mut best: Option<(CelebrationKind, u8)> = None;
    let mut dropped = false;
    for _ in 0..count {
        let seed = now ^ s.total_tool_calls;
        let tick = apply_feed_dispatch(s, seed);
        dropped |= tick.dropped;
        if let Some((k, r)) = tick.detected
            && best.is_none_or(|(b, _)| celebration_rank(k) >= celebration_rank(b))
        {
            best = Some((k, r));
        }
    }
    if let Some((k, r)) = best {
        s.celebration_kind = k;
        s.levelup_renders_remaining = r;
    }
    s.last_fed_at = now;
    FeedBatch { celebration: best.map(|(k, _)| k), dropped }
}

/// Inverse of the ANSI printer for the SGR subset this codebase emits
/// (0 reset, 1 bold, 2 dim, 38;2;r;g;b). Lets string renderers that were not
/// migrated to spans (card, pet/play/treat prose) feed the JSON surface.
/// One `Vec<Span>` per `\n`-separated line; empty-text spans are not emitted;
/// unknown SGR params and non-SGR CSI sequences are dropped.
pub fn parse_ansi(s: &str) -> Vec<Vec<Span>> {
    fn flush(lines: &mut [Vec<Span>], text: &mut String, attrs: &[Attr]) {
        if !text.is_empty() {
            lines.last_mut().expect("at least one line").push(Span { text: std::mem::take(text), attrs: attrs.to_vec() });
        }
    }
    let mut lines: Vec<Vec<Span>> = vec![Vec::new()];
    let mut attrs: Vec<Attr> = Vec::new();
    let mut text = String::new();
    let mut chars = s.chars().peekable();
    while let Some(c) = chars.next() {
        match c {
            '\x1b' if chars.peek() == Some(&'[') => {
                chars.next();
                let mut params = String::new();
                let mut final_byte = None;
                for p in chars.by_ref() {
                    if p.is_ascii_digit() || p == ';' {
                        params.push(p);
                    } else {
                        final_byte = Some(p);
                        break;
                    }
                }
                if final_byte != Some('m') {
                    continue;
                }
                flush(&mut lines, &mut text, &attrs);
                apply_sgr(&mut attrs, &params);
            }
            '\n' => {
                flush(&mut lines, &mut text, &attrs);
                lines.push(Vec::new());
            }
            _ => text.push(c),
        }
    }
    flush(&mut lines, &mut text, &attrs);
    lines
}

fn apply_sgr(attrs: &mut Vec<Attr>, params: &str) {
    let n: Vec<u16> = params.split(';').map(|p| p.parse().unwrap_or(0)).collect();
    let mut i = 0;
    while i < n.len() {
        match n[i] {
            0 => attrs.clear(),
            1 => attrs.push(Attr::Bold),
            2 => attrs.push(Attr::Dim),
            38 if n.get(i + 1) == Some(&2) && i + 4 < n.len() => {
                attrs.retain(|a| !matches!(a, Attr::Fg(_)));
                attrs.push(Attr::Fg(Rgb(n[i + 2] as u8, n[i + 3] as u8, n[i + 4] as u8)));
                i += 4;
            }
            _ => {}
        }
        i += 1;
    }
}

pub fn strip_ansi(s: &str) -> String {
    parse_ansi(s).iter().map(|l| to_plain(l)).collect::<Vec<_>>().join("\n")
}

pub fn lines_json(text: &str) -> Vec<Vec<JsonSpan>> {
    let mut lines = parse_ansi(text);
    if text.ends_with('\n') && lines.last().is_some_and(|l| l.is_empty()) {
        lines.pop();
    }
    lines.iter().map(|l| to_json(l)).collect()

    /// per row == the ANSI row stripped. (Not used for ANSI output — `emit`'s
    /// reset-on-every-change byte pattern is what the statusline goldens pin.)
    pub fn emit_spans(&self, cat_attrs: &[crate::colors::Attr]) -> Vec<Vec<crate::span::Span>> {
        use crate::colors::{Attr, MAGENTA, PINK, YELLOW};
        use crate::span::Span;
        let attrs_for = |col: u8| -> Vec<Attr> {
            match col {
                COL_CAT => cat_attrs.to_vec(),
                COL_YELLOW => vec![Attr::Fg(YELLOW)],
                COL_MAGENTA => vec![Attr::Fg(MAGENTA)],
                COL_PINK => vec![Attr::Fg(PINK)],
                COL_DIM => vec![Attr::Dim],
                _ => vec![],
            }
        };
        let mut rows = Vec::with_capacity(ROWS);
        for y in 0..ROWS {
            let mut row: Vec<Span> = Vec::new();
            let mut cur: Option<u8> = None;
            for &(ch, col) in &self.cells[y * self.w..(y + 1) * self.w] {
                if cur != Some(col) {
                    row.push(Span::new(String::new(), &attrs_for(col)));
                    cur = Some(col);
                }
                row.last_mut().expect("pushed above").text.push(ch);
            }
            rows.push(row);
        }
        rows
    }

    pub width: Option<usize>,

pub fn parse_opts(args: &[String]) -> Result<FrameOpts, String> {
    fn value<'a>(args: &'a [String], flag: &str) -> Result<Option<&'a str>, String> {
        if !crate::cli::has_flag(args, flag) {
            return Ok(None);
        }
        crate::cli::flag_value(args, flag).map(Some).ok_or_else(|| format!("{flag} needs a value"))
    }
    let width = value(args, "--width")?
        .map(|v| v.trim().parse::<usize>().map_err(|_| format!("--width must be a non-negative integer, got {v:?}")))
        .transpose()?;
    let tick = value(args, "--tick")?
        .map(|v| v.trim().parse::<u64>().map_err(|_| format!("--tick must be a non-negative integer, got {v:?}")))
        .transpose()?;
    let context_pct = match value(args, "--context-pct")? {
        None => 0.0,
        Some(v) => {
            let p: f64 = v.trim().parse().map_err(|_| format!("--context-pct must be a number, got {v:?}"))?;
            if !p.is_finite() {
                return Err(format!("--context-pct must be finite, got {v:?}"));
            }
            p.clamp(0.0, 100.0)
        }
    };
    Ok(FrameOpts { width, tick, context_pct, advance: crate::cli::has_flag(args, "--advance") })
}

pub fn run(opts: &FrameOpts) -> i32 {
    // Read-only: never load_or_hatch (it would create state.json).
    let Some(st) = state::load() else {
        crate::json::no_kitten(true);
        return 1;
    };
    let now = state::now_secs();
    let tick = opts.tick.unwrap_or(now);
    let forced_scene = crate::playground::force_scene();
    let playground_enabled = crate::playground::enabled();
    let strip_width = match opts.width {
        Some(w) => crate::playground::clamp_strip(w),
        None => crate::playground::strip_width(),
    };
    let view = kitten_view(
        &ViewInput {
            st: &st,
            now: now as i64,
            frame: (tick % 2) as u8,
            ctx_pct: opts.context_pct,
            forced_scene,
            playground_enabled,
            strip_width,
        },
        || if opts.advance { crate::quip_cache::consume() } else { crate::quip_cache::peek() },
    );
    crate::json::print(&build(&st, now, tick, &view));
    if opts.advance {
        advance(&st, now, view.is_birthday, forced_scene, playground_enabled);
    }
    0
}

pub(crate) fn build(st: &State, now: u64, tick: u64, view: &KittenView) -> FrameJson {
    let sprite = (0..crate::playground::ROWS)
        .map(|i| {
            let line = view.sprite_lines.get(i).cloned().unwrap_or_default();
            to_json(&[Span::new(line, &view.sprite_attrs)])
        })
        .collect();
    let scene = view.scene.as_ref().map(|sv| SceneJson {
        kind: sv.kind,
        elapsed: sv.elapsed,
        duration: sv.duration,
        finale: sv.finale,
        width: sv.width,
        rows: crate::playground::render_scene_spans(
            sv.kind, sv.elapsed, sv.duration, sv.seed, sv.width, view.frame, &view.rarity_attrs,
        )
        .iter()
        .map(|r| to_json(r))
        .collect(),
    });
    let celebration = (st.celebration_kind != CelebrationKind::None).then(|| CelebrationJson {

        remaining_ticks: st.levelup_renders_remaining,
        tick_secs: CELEBRATION_TICK_SECS,
    });
    FrameJson {

        shiny: st.shiny,

        mood: view.mood.to_string(),
        sprite,
        speech: to_json(&[Span::new(view.speech.clone(), &view.speech_attrs)]),
        speech_source: view.speech_source.as_str().to_string(),

        celebration,
    }
}

usage() {
    echo "usage: bash install.sh                    # wire statusLine + feed/turn hooks (classic)"
    echo "       bash install.sh --uninstall-hooks  # remove purrgotchi feed/turn hooks, keep statusLine"
}

MODE="install"
case "${1:-}" in
    "")                MODE="install" ;;
    --uninstall-hooks) MODE="uninstall-hooks" ;;
    -h|--help)         usage; exit 0 ;;
    *)                 echo "unknown option: $1"; usage; exit 2 ;;
esac

# --- Uninstall hooks (v4 mod migration) -------------------------------------
# The Purrgotchi mod owns feed/turn wiring; leaving the settings.json hooks in
# place would feed every tool call twice. statusLine is kept (it never counts
# anything). Needs only jq — never the compiled binary.
if [ "$MODE" = "uninstall-hooks" ]; then
    echo "Purrgotchi: removing feed/turn hooks from $SETTINGS (statusLine is kept)"
    if ! command -v jq >/dev/null 2>&1; then
        echo "  MISSING: jq (https://jqlang.github.io/jq/download/)"
        exit 1
    fi
    if [ ! -f "$SETTINGS" ]; then
        echo "  No settings.json — nothing to do."
        exit 0
    fi
    if ! jq empty "$SETTINGS" 2>/dev/null; then
        echo "  ERROR: $SETTINGS is not valid JSON. Fix it (or restore a .bak) and re-run."
        exit 1
    fi
    UNINSTALL_FILTER='
      def drop_purr:
        (. // [])
        | map(.hooks = ((.hooks // []) | map(select(((.command // "") | test("purrgotchi")) | not))))
        | map(select((.hooks | length) > 0));
      def prune($k): if (.[$k] // null) == [] then del(.[$k]) else . end;
      if (.hooks | type) != "object" then . else
        .hooks |= (
          (if has("PostToolUse") then .PostToolUse |= drop_purr else . end)
          | (if has("UserPromptSubmit") then .UserPromptSubmit |= drop_purr else . end)
          | prune("PostToolUse") | prune("UserPromptSubmit")
        )
        | if .hooks == {} then del(.hooks) else . end
      end'
    if ! jq "$UNINSTALL_FILTER" "$SETTINGS" > "${SETTINGS}.new" 2>/dev/null \
       || ! jq empty "${SETTINGS}.new" 2>/dev/null; then
        rm -f "${SETTINGS}.new"
        echo "  ERROR: could not rewrite settings.json with jq. Settings unchanged."
        exit 1
    fi
    if [ "$(jq -S . "$SETTINGS")" = "$(jq -S . "${SETTINGS}.new")" ]; then
        rm -f "${SETTINGS}.new"
        echo "  No Purrgotchi hooks found — settings.json unchanged."
        exit 0
    fi
    BACKUP="${SETTINGS}.bak.$(date +%Y%m%d-%H%M%S)"
    cp "$SETTINGS" "$BACKUP"
    echo "  Backup: $BACKUP"
    mv "${SETTINGS}.new" "$SETTINGS"
    echo "  Removed purrgotchi feed/turn hooks. statusLine left in place."
    echo "  To rollback: cp \"$BACKUP\" \"$SETTINGS\""
    exit 0
fi
